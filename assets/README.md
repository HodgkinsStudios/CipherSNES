# CipherSNES official project artwork

`CipherSNES_icon.png` is the full-resolution, user-approved HodgkinsStudios CipherSNES neon badge. Keep this PNG as the single source of truth for branding.

- `CipherSNES_icon_256.png`: Linux desktop / AppStream icon
- `CipherSNES_about.ppm`: reduced P6 RGB image used by the dependency-free X11 About and titlebar implementation
- `CipherSNES.ico`: multiresolution Windows executable icon used by `CipherSNES.rc`
- `CipherSNES.icns`: native macOS Finder / Dock bundle icon

GTK uses the same `CipherSNES_icon.png` for its window and About dialog on all desktop platforms. Do not reintroduce the former About screenshot unless replaced with a real capture showing the current artwork.
